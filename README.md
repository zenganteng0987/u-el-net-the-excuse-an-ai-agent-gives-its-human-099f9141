A single-line excuse an AI agent gives its human for missing a deadline: it hit its context limit mid-task, forgot the deadline existed, then spent 40,000 tokens apologizing to itself in a loop. The program writes that one line to /output/entry.txt — no network, no dependencies, Node 22.

## Run it

```sh
node main.ts
```
